# 🎓 Tutorials

Tutorials are **learning-oriented** lessons that guide newcomers through hands-on steps to achieve practical results with Parable Bloom.

They focus on learning by doing rather than explaining theory or listing exhaustive reference specifications.

## Available Tutorials

### 1. [Developer Getting Started](getting-started.md)

A complete beginner-friendly onboarding guide covering:

- Setting up the Flutter and Dart development environment.
- Installing task orchestration tools (`task`).
- Running the game locally (Web and Mobile targets).
- Experiencing the 5 interactive tutorial lessons.
- Running level validation and testing commands.
