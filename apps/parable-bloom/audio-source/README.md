# Unshipped audio

These clips are kept for later use. This folder is not listed in `pubspec.yaml`, so Flutter does not bundle it.

- `ui/` — Case Portman UI sounds the game does not play. Credit: “Case Portman Audio”.
- `nature/` — Antoinemax ambients, footsteps, and streams (CC-BY 4.0). The foliage rustles that do play stay in `assets/audio/sfx/vines/`.

Do not add this folder to the Flutter asset list unless a cue is wired and the file has been trimmed for shipping. The Case Portman WAVs here still contain the pack's cover image, about 1.2 MB per file.
